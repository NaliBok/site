# Текстовая RPG

Ванильный JavaScript без сборщика и фреймворков. `game.js` — общий игровой движок для одиночной игры в браузере и сетевого режима на Node.js.

## GitHub Pages (одиночная игра)

1. Загрузите файлы из корня проекта в корень репозитория GitHub: `index.html`, `styles.css`, `client.js`, `game.js`, `server.js`, `package.json`, `test-engine.js`, `README.md`.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
4. После публикации одиночная игра будет работать без сервера. Персонаж сохраняется в `localStorage` браузера.

## Сетевой сервер на Render

1. Создайте в Render новый **Web Service** из того же GitHub-репозитория.
2. **Root Directory** оставьте пустым.
3. Укажите Build Command `npm install` и Start Command `npm start`.
4. После запуска скопируйте публичный адрес сервиса, например `https://your-service.onrender.com`.
5. На странице GitHub Pages вставьте этот адрес в поле **WebSocket-сервер**. Поле принимает как `https://…`, так и `wss://…`; приложение само выберет HTTPS для проверки и WSS для игры. Нажмите **Проверить сервер**, затем **Играть по сети**.

Сервер слушает порт из переменной окружения `PORT`, отдаёт проверку доступности на `/health` и принимает WebSocket-подключения на `/ws`. Для локального запуска выполните `npm install`, затем `npm start`; страница будет доступна по адресу `http://localhost:3000`.

## Сохранения и ограничения хостинга

- В одиночном режиме прогресс сохраняется в браузере каждые 5 секунд и перед закрытием вкладки.
- На сервере прогресс игроков записывается в `players.json`, который автоматически создаётся в корне при первом сохранении. Токен игрока позволяет восстановить персонажа при переподключении.
- На бесплатном тарифе Render сервис засыпает после 15 минут без входящего HTTP-трафика и сообщений WebSocket. Пробуждение обычно занимает около минуты; экран входа проверяет `/health`, чтобы запустить сервис до подключения.
- Файловая система бесплатного хостинга временная: локальные изменения могут исчезнуть при засыпании, перезапуске или новом развёртывании. Поэтому `players.json` на бесплатном Render не является вечным хранилищем. Для долговременных онлайн-сохранений нужна постоянная база данных или подключённый persistent disk.
- Одиночная игра не обращается к серверу, если вы не выбрали сетевой режим.

## Проверка кода

```sh
npm run check
```

Команда проверяет синтаксис всех JavaScript-файлов и запускает тест игрового движка: вход, переход, исследование, бой, тики, награды, задания и восстановление сохранения.
